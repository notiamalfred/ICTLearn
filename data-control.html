Databases vs Spreadsheets

Why use a database?

For managing a large amount of data, a database is usually a better choice than a spreadsheet.

A database management system (DBMS) allows us to organise, store and retrieve data efficiently with graphical user interface (GUI).

Garbage In, Garbage Out

The principle

If the input data is wrong or low-quality, the output information will also be wrong or low-quality. Data control (validation and verification) is essential to prevent this.

Data Validation

Validation vs Verification

Data validation: done by computers

Data verification: done by humans

Types of data validation

TypeFunctionExample
Presence checkEnsures that there must be data in the required fields.An applicant must provide their name.
Fixed value checkEnsures that the data can only be selected from a list of specific values.The sex of an applicant must be either "M" or "F".
Type checkEnsures that the data must be of a certain type.The age of an applicant must be a number.
Range checkEnsures that the data must be within a certain range.The age of an applicant must be larger than 12.
Length checkEnsures that the length of the data must match certain criteria.An applicant must provide an 8-digit phone number.
Format checkEnsures that the data must be in a specific format.The email address of an applicant must contain an "@" symbol.
Uniqueness checkThe data must be unique for the field.Each student can apply once only. Thus, there should not be any duplicated student IDs among the applicants.

User Interface Designs for Validation

Common UI controls

There are different user interface designs to make data validation easier:

Drop-down list

Data validation: Fixed value check — only one of the specific values can be input.

Radio button

Data validation: Fixed value check — only one of the specific values can be input.

Checkboxes

Data validation: Fixed value check — only the specific values can be input. Multiple values can be selected.

Date picker

Data validation: Type check — only dates can be input. Format check — the date must be in a certain format, such as "DD/MM/YYYY".
