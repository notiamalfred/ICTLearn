Information Systems

People, processes and data — and how they turn input into information.

Introduction

What is an Information System?

An information system is implemented for automating processes, reducing human errors and improving efficiency. It combines people, hardware, software, data and networks to collect, process, store and distribute information.

Roles in an Information System

Three key roles

RoleMain responsibility
Computer engineer Design, build and integrate the hardware, software and network.
Systems analyst Design a system to fulfil the business needs and the requirements provided by end users. Analyse the time, cost and feasibility of building the system.
Programmer Develop the system according to the design given by systems analysts.

Data vs Information

What is data?

Data is a collection of unorganised facts which usually has no meaning on its own.

After processing, data is put into context and converted into information.

Input–Process–Output Cycle

Three stages

  1. Data is input into the computer.
  2. The computer processes the input data.
  3. Meaningful information is output from the computer.

Information Processing Steps

From raw data to meaningful information

Information processing converts raw data into meaningful information through seven steps:

  1. Collection
  2. Organisation
  3. Storage
  4. Processing
  5. Analysis
  6. Transmission
  7. Presentation
