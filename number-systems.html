Number Bases

Decimal, binary and hexadecimal

People usually use a decimal system (also known as denary system) for counting. In contrast, digital devices use a binary system.

Binary numbers are used because each digit of a binary number can represent one bit (21) of digital data.

A decimal number is a number in base 10, while a binary number is a number in base 2.

A hexadecimal number is a number in base 16. It's commonly used because each digit can represent 4 bits (24) of digital data.

Each binary digit represents 1 bit; each hex digit represents 4 bits.

Unsigned Integers

Representation of unsigned integers

Unsigned integers only include positive integers and zero.

An unsigned integer represented in N-bits ranges from 0 to 2N − 1. For example, if we allocate 3 bits to store an unsigned integer, it can be as small as 0 (000) and as large as 23 − 1 = 7 (111).

Signed Integers

Representation of signed integers

Signed integers include positive integers, negative integers and zero.

A signed integer represented in N-bits usually ranges from −2N−1 to 2N−1 − 1. For example, if we allocate 3 bits to store a signed integer, it can be as small as −23−1 = −4 and as large as 23−1 − 1 = 3.

e.g. To represent 2710 in 6 bits, we simply convert 2710 into a 6-digit binary number, which is 011011, instead of 11011.

Sign & Magnitude

Sign & magnitude

1st bit represents negative and positive:

  • 0 = (+)
  • 1 = (−)
e.g. 01002 = ±410, 11002 = ±410

Drawback: two representations of zero exist — positive zero (+0) and negative zero (−0).

Two's Complement

Two's complement

Two's complement: a method for representation of signed integers in bit pattern.

For a two's complement representation: if the first bit is 0, it represents a non-negative number; if the first bit is 1, it represents a negative number.

For a 3-bit two's complement representation, 101, we can convert it into a decimal number by expanding it like below:

Digit101
Place value−(22) = −421 = 220 = 1
Value of the digit−4 × 1 = −42 × 0 = 01 × 1 = 1

Therefore, 1012 = −4 + 0 + 1 = −310.

For a 4-bit two's complement representation, 0101, we can convert it into a decimal number by expanding it like below:

Digit0101
Place value −(23) = −8 22 = 4 21 = 2 20 = 1
Value of the digit −8 × 0 = 0 4 × 1 = 4 2 × 0 = 0 1 × 1 = 1

Therefore, 0101 = 4 + 0 + 1 = 510.

The two's complement of an integer X is the two's complement representation of −X. For example, the two's complement of 310 is 101, which is also the two's complement representation of −310.

Flipping bits (among negative and positive) (two's complement representation):

  • 1 → 0
  • 0 → 1
  • Then add 1 to the result

Character Encoding

English: ASCII

English: American Standard Code for Information Interchange (ASCII) is one of the commonly used character encoding systems. ASCII usually uses 7 bits to represent a character (letters, numbers, symbols). Sometimes, ASCII is extended to 8 bits (1 byte) because of one of the following reasons:

  • It can represent more characters by using the extra bit
  • It can use the extra bit as a parity bit
  • Some systems process data in a byte

Chinese

  • Traditional Chinese is often encoded by Big-5 code
  • Simplified Chinese is often encoded by Guobiao (GB) code
  • Both encoding systems use 2 bytes (16 bits) to store a character and contain over 10000 characters, including English letters, digits and symbols.
  • Both encoding systems are not interchangeable. If a text file or a website is encoded by Big-5 code, but is decoded by Guobiao code, instead of being translated to simplified Chinese, the text will be displayed as garbled text.

Multilingual: Unicode

If multiple languages are expected in a text file or a website, a character encoding system named Unicode will be used.

Unicode can be extended to represent 1000000 characters.
