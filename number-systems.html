Number Bases

Decimal, binary and hexadecimal

People usually use a decimal system (also known as denary system) for counting. In contrast, digital devices use a binary system.

  • A decimal number is a number in base 10.
  • A binary number is a number in base 2.
  • A hexadecimal number is a number in base 16. It is commonly used because each digit can represent 4 bits (24) of digital data.

Each binary digit represents 1 bit; each hex digit represents 4 bits.

Binary numbers are used because each digit of a binary number can represent one bit (21) of digital data.

Unsigned Integers

Range and representation

Unsigned integers only include positive integers and zero.

An unsigned integer represented in N bits ranges from 0 to 2N − 1.

For example, if we allocate 3 bits to store an unsigned integer, it can be as small as 0 (000) and as large as 23 − 1 = 7 (111).

Signed Integers

Sign & magnitude

Signed integers include positive integers, negative integers and zero.

A signed integer represented in N bits usually ranges from −2N−1 to 2N−1 − 1.

For example, if we allocate 3 bits to store a signed integer, it can be as small as −23−1 = −4 and as large as 23−1 − 1 = 3.

Sign & magnitude: the first bit represents negative/positive (0 = +, 1 = −).

e.g. 01002 = +410, 11002 = −410

Drawback: two representations of zero exist — positive zero (+0) and negative zero (−0).

Two's Complement

Representation of signed integers in bit pattern

For a two's complement representation:

  • If the first bit is 0, it represents a non-negative number.
  • If the first bit is 1, it represents a negative number.

Example 1: 3-bit two's complement, 101:

Digit101
Place value−(22) = −421 = 220 = 1
Value of the digit−4 × 1 = −42 × 0 = 01 × 1 = 1

Therefore, 1012 = −4 + 0 + 1 = −310.

Example 2: 4-bit two's complement, 0101:

Digit0101
Place value−(23) = −822 = 421 = 220 = 1
Value of the digit−8 × 0 = 04 × 1 = 42 × 0 = 01 × 1 = 1

Therefore, 0101 = 4 + 0 + 1 = 510.

Finding the two's complement of an integer X

The two's complement of an integer X is the two's complement representation of −X. For example, the two's complement of 310 is 101, which is also the two's complement representation of −310.

Flipping bits (two's complement representation):

  1. 1 → 0
  2. 0 → 1
  3. Then add 1 to the result.

Character Encoding

English: ASCII

American Standard Code for Information Interchange (ASCII) is one of the commonly used character encoding systems.

ASCII usually uses 7 bits to represent a character (letters, numbers, symbols). Sometimes, ASCII is extended to 8 bits (1 byte) because of one of the following reasons:

  • It can represent more characters by using the extra bit.
  • It can use the extra bit as a parity bit.
  • Some systems process data in a byte.

Chinese

  • Traditional Chinese is often encoded by Big-5 code.
  • Simplified Chinese is often encoded by Guobiao (GB) code.
  • Both encoding systems use 2 bytes (16 bits) to store a character and contain over 10000 characters, including English letters, digits and symbols.
  • Both encoding systems are not interchangeable. If a text file or a website is encoded by Big-5 code, but is decoded by Guobiao code, instead of being translated to simplified Chinese, the text will be displayed as garbled text.

Multilingual: Unicode

If multiple languages are expected in a text file or a website, a character encoding system named Unicode will be used. Unicode can be extended to represent 1000000 characters.
