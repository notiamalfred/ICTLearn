Glossary of Key Terms

Every definition from the notes, in one place.

Information system

A system implemented for automating processes, reducing human errors and improving efficiency.

Data

A collection of unorganised facts which usually has no meaning on its own.

Information

Data that has been processed and put into context so that it has meaning.

Input–Process–Output cycle

Data is input, processed by the computer, and meaningful information is output.

Database management system (DBMS)

Software that allows us to organise, store and retrieve data efficiently with a graphical user interface (GUI).

Garbage in, garbage out

If input data is wrong or low-quality, the output information will also be wrong or low-quality.

Data source error

Incorrect data is provided by the data source.

Transcription error

Data is misread, misheard or mistyped (e.g. 1 vs l, 0 vs O).

Transposition error

Incorrect placement of the data (e.g. 12345 → 12354).

Data validation

Checks done by computers to ensure data entered is reasonable and follows rules. Includes presence, fixed value, type, range, length, format and uniqueness checks.

Data verification

Checks done by humans to ensure data has been entered correctly (inputting data twice, double data entry).

Check digit

An extra digit appended to a code to help detect errors during data transmission or entry.

Parity bit / Parity check

A bit appended to the end of a binary code so that the total number of 1s is even (even parity) or odd (odd parity), helping detect transmission errors.

Binary

A number system in base 2. Each digit (0 or 1) represents one bit of digital data.

Hexadecimal

A number system in base 16. Each hex digit represents 4 bits of digital data.

Unsigned integer

An integer that includes only positive integers and zero. In N bits, ranges from 0 to 2N − 1.

Signed integer

An integer that includes positive integers, negative integers and zero. In N bits, usually ranges from −2N−1 to 2N−1 − 1.

Sign & magnitude

A method for representing signed integers where the first bit represents the sign (0 = positive, 1 = negative) and the rest represent the magnitude. Has a drawback: two representations of zero.

Two's complement

A method for representing signed integers in bit pattern. If the first bit is 0, the number is non-negative; if the first bit is 1, the number is negative. To negate, flip all bits and add 1.

ASCII

American Standard Code for Information Interchange. Uses 7 bits (sometimes extended to 8 bits / 1 byte) to represent a character.

Big-5 code

A character encoding system for Traditional Chinese. Uses 2 bytes per character.

Guobiao (GB) code

A character encoding system for Simplified Chinese. Uses 2 bytes per character.

Unicode

A character encoding system used when multiple languages are expected. Can represent 1,000,000 characters using 1–4 bytes per character.

Barcode

Codes consisting of bars and spaces of different widths to represent a text string, often a product ID. Elements include the barcode symbol, quiet zones, start/end characters and the human-readable text string.

Quiet zone

An empty margin at each end of a barcode symbol (or around the four sides of a QR code). If it is too small, scanning becomes difficult.

QR code

Quick Response code. Black dots arranged in a white square background, representing a text string (often a URL, phone number or email). Contains position patterns, an alignment pattern and error-correction data for fault tolerance.

Analog data

Data represented in a physical way with continuous values, such as sound waves, written text and drawings.

Digital data

Data represented in discrete symbols (like "0" and "1"), such as text documents, digital photos and audio files.

Digitalisation

The conversion of analog data to digital data. Consists of discretisation (sampling) and quantisation.

Discretisation (sampling)

The process of sampling an analog signal at a regular time interval. The length of this interval determines the sampling rate.

Quantisation

Rounded sampled values to a fixed set of discrete values (such as integers), so the analog signal is stored as a sequence of integers.

Optical character recognition (OCR)

A technique used to convert a digital image of text into editable text.

Lossless compression

Compression in which no data is lost. The original file can be retrieved completely once decompressed.

Lossy compression

Compression in which some data is lost.

Compression ratio

Uncompressed size ÷ Compressed size.

Plain text

A text file that stores characters only. Example: txt.

Formatted text

A text file that stores characters and their formatting data (font, size, colour, line spacing, alignment, etc.). Examples: rtf, doc/docx, odt, pages, pdf.
