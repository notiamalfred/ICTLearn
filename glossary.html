Glossary of Key Terms

Every definition from the notes, in one place.

Information system

A system implemented for automating processes, reducing human errors and improving efficiency.

Computer engineer

Designs, builds and integrates the hardware, software and network.

Systems analyst

Designs a system to fulfil the business needs and the requirements provided by end users. Analyses the time, cost and feasibility of building the system.

Programmer

Develops the system according to the design given by systems analysts.

Data

A collection of unorganised facts which usually has no meaning on its own.

Information

Data that has been processed and put into context so that it has meaning.

Input–Process–Output cycle

Data is input into the computer, the computer processes the input data, and meaningful information is output.

Information processing

Converts raw data into meaningful information through collection, organisation, storage, processing, analysis, transmission and presentation.

Database

For managing a large amount of data, a database is usually a better choice than a spreadsheet.

Database management system (DBMS)

Allows us to organise, store and retrieve data efficiently with graphical user interface (GUI).

Garbage in, garbage out

If input data is wrong or low-quality, the output information will also be wrong or low-quality.

Data source error

Incorrect data is provided by data source.

Transcription error

Data is misread, misheard or mistyped. 購錯. 1 vs l, 0 vs O.

Transposition error

Incorrect placement of the data (e.g. 12345 → 12354).

Data validation

Checks done by computers. Includes presence, fixed value, type, range, length, format and uniqueness checks.

Data verification

Checks done by humans. Includes inputting data twice and double data entry.

Presence check

Ensures that there must be data in the required fields.

Fixed value check

Ensures that the data can only be selected from a list of specific values.

Type check

Ensures that the data must be of a certain type.

Range check

Ensures that the data must be within a certain range.

Length check

Ensures that the length of the data must match certain criteria.

Format check

Ensures that the data must be in a specific format.

Uniqueness check

The data must be unique for the field.

Check digit

An extra digit appended to a code to help detect errors during data transmission or entry.

Parity check

To help detect errors during data transmission, a parity bit, similar to the check digit, can be appended to the end of the binary code to ensure that the total number of 1s in the code is even or odd.

Binary

A number system in base 2. Each digit of a binary number can represent one bit (21) of digital data.

Hexadecimal

A number system in base 16. Each digit can represent 4 bits (24) of digital data.

Unsigned integer

Only includes positive integers and zero. In N-bits, ranges from 0 to 2N − 1.

Signed integer

Includes positive integers, negative integers and zero. In N-bits, usually ranges from −2N−1 to 2N−1 − 1.

Sign & magnitude

1st bit represents negative and positive (0 = +, 1 = −). Drawback: two representations of zero exist (+0 and −0).

Two's complement

A method for representation of signed integers in bit pattern. If the first bit is 0, it represents a non-negative number; if the first bit is 1, it represents a negative number. To negate: flip all bits and add 1.

ASCII

American Standard Code for Information Interchange. Uses 7 bits to represent a character (letters, numbers, symbols). Sometimes extended to 8 bits (1 byte) to represent more characters, use the extra bit as a parity bit, or process data in a byte.

Big-5 code

Traditional Chinese is often encoded by Big-5 code. Uses 2 bytes (16 bits) per character.

Guobiao (GB) code

Simplified Chinese is often encoded by Guobiao (GB) code. Uses 2 bytes (16 bits) per character.

Unicode

Character encoding system used if multiple languages are expected in a text file or a website. Can be extended to represent 1000000 characters.

Barcode

Codes that consist of bars and spaces of different widths to represent a text string. This string is often a sequence of numbers representing a product ID.

Quiet zone

Empty margin at each end of the barcode symbol. If too small, it will be hard to scan the barcode symbol. For QR codes, quiet zone around the four sides.

Start character and end character

Indicate the start and the end of the barcode symbol respectively.

QR code

Quick Response code. Made up of numerous black dots arranged in a white square background. Represents a text string which is usually a URL, a phone number or an email address.

Position pattern

Located at three of the four corners in a QR code. Allows the QR code to be scanned from any direction.

Alignment pattern

When the scanner is at an angle, the QR code will look distorted. By referring to the alignment pattern, the QR scanner can adjust the scanned image and fix the distortion.

Fault tolerance (QR code)

QR codes contain error-correction data, so they can still be decoded when rotated, distorted, dirty or partly covered.

Analog data

模擬資料. Represented in a physical way with continuous values, such as sound waves, written text and drawings.

Digital data

數碼資料. Represented in discrete symbols (like "0" and "1"), such as text documents, digital photos and audio files.

MP3

Compressed audio.

WAV

Raw audio.

Digitalisation

The conversion of analog data to digital data. Can be broken down into two parts: discretisation and quantisation.

Discretisation

The value of an analog signal is sampled at a regular time interval. The length of this time interval determines the sampling rate.

Quantisation

After discretisation, sampled values are rounded to a fixed set of discrete values, such as integers.

Sampling rate

A higher sampling rate means more samples are taken in a given period of time. The resulting data is thus closer to the original waveform and has less data loss during digitalisation.

Optical character recognition (OCR)

Used to convert a digital image (from scanning a book) into an electronic book.

Lossless compression

No data is lost after compression. The original file can be retrieved completely once decompressed.

Lossy compression

Some data is lost after compression.

Compression Ratio

Uncompressed Size / Compressed Size.

Plain text

Stores characters only. Example: txt.

Formatted text

Stores characters and their formatting data, such as font type, font size, font colour, line spacing, text alignment, etc. Its file size is relatively larger than that of plain text. Examples: rtf, doc/docx, odt, pages, pdf.

txt

Plain text. Relatively small file size. Widely supported by different operating systems.

rtf

Formatted text. Widely supported by different operating systems. Can contain images and hyperlinks.

doc / docx

Formatted text. Native to Microsoft Word. Contain multimedia, including images, audios, videos, and hyperlinks.

odt

Formatted text. Native to OpenOffice Writer and LibreOffice. Contain multimedia, including images, videos, audio and hyperlinks.

pages

Formatted text. Native to Apple Pages. Contain multimedia, including images, audios, videos and hyperlinks.

pdf

Formatted text. Native to Adobe Acrobat, but is usually exported from other file formats. Contain multimedia, including images, audios, videos and hyperlinks. Provides cross-platform support.

BMP

Uncompressed image format. Has the largest file size and highest quality. File size example: 1376 KB.

PNG

Lossless compressed image format. File size example: 609 KB. Compression ratio: 1376 / 609 = 2.26.

JPG

Lossy compressed image format. File size example: 5 KB. Compression ratio: 1376 / 5 = 275.
