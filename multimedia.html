Multimedia, Images, Audio & Video

Image types, attributes, compression and file formats for multimedia.

Bitmap vs Vector Images

Two types of images

There are two types of images:

Bitmap images are stored as a series of little squares called pixels. Vector images are stored as mathematical formulae, which connect points to draw lines, curves, circles, polygons, etc.

TypeAdvantage
Bitmap image • Real life digital photos are usually bitmap images
• It can be edited by common image editing software like Microsoft Paint
Vector image • Its file size tends to be smaller
• It does not have rough edges and will not become blurry when scaled up or down
• Usually used for logos or animations

Image Attributes

Four important attributes

An image file has four important attributes: resolution, colour depth, aspect ratio and transparency.

Colour Depth

Colour depth is the number of bits used to represent the colour of a pixel. The higher the colour depth an image has, the more colours it can include.

Resolution

Resolution is the total number of pixels in an image. It is usually represented as "number of pixels per row × number of pixels per column", i.e. "width × height".

High-resolution imageLow-resolution image

Aspect Ratio

The aspect ratio is the ratio of an image's width to its height. Common ratios include 4:3 and 16:9. When an image is placed into a container of a different aspect ratio, you can either leave blank spaces (letterboxing) or crop the image.

Transparency

Transparency means that whether an image can have transparent areas or not.

Image File Size Calculation

Formula

File size (bits) = Colour depth × Resolution = Colour depth × Width in pixels × Height in pixels

Compression

Lossless vs lossy

Lossless compression means no data is lost after compression. The original file can be retrieved completely once decompressed.

Worked example — lossless compression

Text string, SSSSSSMON3D3D3D3D3DAAAABBBAAAABBBAAA, contains 40 characters. To represent this string using fewer characters, we may follow the steps below:

  1. Find the repeating patterns
  2. Count the number of the same repeating patterns and add that number before the patterns
    6SSSSSS1MON53D3D3D3D4AAAA3BBB3AAA3BBB3AAA3BBB2AA
  3. If that pattern contains backslash, add a backslash before every backslash.
  4. If that pattern contains numbers, enclose it with backslashes to avoid confusion.
    6SSSSSS1MON5\3D3D3D3D3D\4AAA\3BBB3AAA3BBB3AAA3BBB2AA
  5. Delete all but one repeating pattern
    6S1MON5\3D\4A3B3A3B3A2A

Lossy compression means some data is lost after compression.

(Best audio quality) (Largest file size) Uncompressed, lossless compression, lossy compression (Smallest file size) (Worst audio quality)

Note that uncompressed audio and lossless compressed audio have the same level of audio quality.

Compression Ratio = Uncompressed Size / Compressed Size

Audio Files

Audio attributes

An audio file has three important attributes: bit depth, sampling rate and the number of channels.

Bit depth is the number of bits used to represent an audio sample. The higher the bit depth an audio has, the more sound levels it can represent and the better quality it has.

Sampling rate is the number of audio samples taken per second. The higher the sampling rate an audio has, the more samples are captured in a period of time. This means the audio is closer to the original sound wave and hence has better quality.

Number of channels: sometimes, an audio file has more than one channel.

Audio file size calculation

File size = Bit depth × Number of channels × Sampling rate × Duration

Video Files

Video attributes

A video is a sequence of images shown within a certain duration and potentially one or more audio tracks. A video file has four important attributes: colour depth, resolution, frame rate and duration.

Frame rate (fps) is the number of frames shown per second.

Video file size calculation

File size = Colour depth × resolution × frame rate × duration + size of the audio track

Text File Formats

Plain text vs formatted text

There are two types of text:

  • Plain text stores characters only
  • Formatted text stores characters and their formatting data, such as font type, font size, font colour, line spacing, text alignment, etc. Its file size is relatively larger than that of plain text.
File size per character × number of characters ≈ file size of a plain text file

File Headers and Metadata

Where metadata is stored

Multimedia (text, image, video, audio) can be stored in various file formats and have different attributes. The file format and the metadata of a file are usually stored in its file header.

Different file formats are supported by different software and operating systems. Some file formats involve compression and suffer from data loss while some do not.
